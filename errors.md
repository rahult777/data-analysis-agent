**2026-09-19 | Excel True/False columns with blank cells load as float64 (1.0/NaN/0.0), not bool or object — observation, NOT yet fixed (recorded during Build A as a named exception to its "no new errors.md entry" scope)**
Unlike CSV, where blanks make the column object dtype, pd.read_excel turns True/blank/False into float64 `[1.0, NaN, 0.0]` (reproduced on pandas 2.2.0 with an openpyxl-written .xlsx). The column counts as numeric, not bool, so Build A's `is_bool_dtype` exclusion does not reach it. It does not crash, but it takes the random-sample branch (a misleading homogeneous sample on imbalanced data) and gets IQR/mean stats, as if it were a continuous measure. Solution: not applied; needs its own design (for example, detecting 0/1-only float columns loaded from Excel).
